# Website project rules
The owner is not a developer. Explain everything in plain, simple English.

## Current setup
- This is a **static website** (HTML, CSS, JavaScript) with no build step, because npm package installs were blocked when it was built. Vercel serves the repository root as-is.
- All business text, prices, contact details and the TODO list live in `_src/content.py`. Pages are generated by `python3 _src/build.py`; never hand-edit the generated `.html` files.
- Moving to Next.js (App Router) + TypeScript + Tailwind is planned once installs are allowed; then follow the team's standard Next.js Vercel rules.

## Always
- Before any design or content work, follow the Taste Skill (design-taste-frontend), the ui-ux-pro-max skill and the design-motion-principles skill for all animation.
- Never invent reviews, prices, awards, statistics or client names.
- Brand name: The HiNoterBook ("Your In-person AI NoteTaker"); gift: HiNoter Earpods (approved by the owner).
- RRP R7 499 once-off. Maximum discount 10% (scratch card) makes it R6 749. Free earpods worth R999 with every pre-order. Prices in Rand, written like R7 499.
- No floating WhatsApp button (the owner asked for it to be removed). WhatsApp links use https://wa.me/27XXXXXXXXX format.
- Keep the Privacy Policy page (POPIA).
- Correct at 390px, 768px and 1440px. No sideways scrolling. WCAG AA contrast. Respect prefers-reduced-motion.
- Pre-order emails: `api/pre-order.js` (a Vercel serverless function, no packages) sends the order to info@survivalguide.co.za and a thank-you email to the customer through Resend, from orders@hinoterbook.co.za. The only secret is the Vercel environment variable `RESEND_API_KEY` (set in Vercel by the owner). Never put keys in code and never commit .env files.
- File names lowercase, no spaces.
- Before finishing any task: rebuild with `python3 _src/build.py`, check the pages in a browser, then commit and push.
